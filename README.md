# uplevel-demo

A standalone, public preview of the UpLevel attendee site UI, built from a
**fully synthetic dataset** (15 fake attendees — `Demo Founder One`,
`demo1@example.com`, fabricated LinkedIn URLs). No real attendee data has
ever been in this repository.

This repo exists only so the demo can be deployed via GitHub Pages while
the real project (a separate, private repository) stays private. It is
deliberately kept out of that repository entirely — not a branch or
subfolder of it — so there's no risk of demo content and real attendee
data ever mixing.

Source: generated by `scripts/generate_pages.py --demo-banner` in the
main UpLevel project, from `data/demo-attendees.json`. To refresh this
preview, regenerate `site-demo/` there and copy `uplevel/`, `lookbook/`,
and `assets/` over the corresponding folders here, then commit and push.
